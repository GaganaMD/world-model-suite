# Physical-AI generation plan

Claude Opus 5, Llama 3.3 70B Instruct) × two independent generations = 30
calls. No calls are authorized or launched. Each output will be evaluated with
the external success/failure/unsafe predicates, structural F1, planning regret,
reachability, and reversibility metrics.
